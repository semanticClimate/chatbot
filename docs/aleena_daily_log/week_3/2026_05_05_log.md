### What I Understood From the New Architecture

> To preface, AI was used to help rephrase the understanding below for better clarity.

The `climate_streamlit` directory contains the full source code for the Climate Academy Chatbot, built as a professional web application using Streamlit.

This chatbot uses **Retrieval-Augmented Generation (RAG)**, meaning it retrieves relevant information from the Climate Academy student book before generating grounded answers.

---

## 🚀 Main Application Files

### `app.py`
- Main entry point of the application
- Handles UI layout
- Creates split-view interface:
  - Chat on the left
  - Book viewer on the right
- Initializes vector database
- Controls overall application flow

### `Getting_started.md`
- Setup and configuration guide
- Explains installation and deployment process

---

## ⚙️ Core Logic & Configuration

### `config_loader.py`
- Manages:
  - File paths
  - API keys
  - App configuration
- Ensures correct location of HTML/PDF resources

### `html_sectioning.py`
- Breaks large HTML student book into:
  - Smaller paragraphs
  - Searchable sections
- Essential for efficient RAG retrieval

### `db.py`
- Handles chatbot logging
- Uses local SQLite database (`chatbot_logs.db`)
- Useful for:
  - Analytics
  - Debugging
  - Conversation tracking

### `styling.py`
- Custom CSS styling
- Maintains Climate Academy branding and interface appearance

---

## 📁 Key Subdirectories

### `rag/`
Core retrieval system.

#### `indexing.py`
- Builds ChromaDB vector database from source book

#### `retrieve.py`
- Retrieves most relevant knowledge snippets based on user query

#### `sources.py`
- Generates clickable source references linked to book sections

---

### `ui/`
Frontend UI modules.

#### `chat_column.py`
- Main chatbot conversation interface

#### `book_viewer.py`
- Interactive book display panel

#### `sidebar.py`
- Sidebar navigation and settings

---

### `llm/`
Large Language Model integration.

#### `groq_client.py`
- Connects to Groq API
- Handles inference

#### `ask.py`
- Combines:
  - User query
  - Retrieved source material
  - Prompt generation

---

### `services/`
Business logic layer.

#### `chat_service.py`
- Coordinates retrieval + generation flow

#### `conversation.py`
- Manages:
  - Chat history
  - CSV export
  - JSON export

---

### `pdf/`
PDF integration system.

- Links chatbot answers directly to PDF pages
- Enhances source traceability

## Key Takeaway

The refactored architecture is significantly more modular, making it:

- Easier to debug
- Easier to maintain
- Easier to scale
- More professional for collaborative development

Rather than one large codebase, responsibilities are split cleanly across services, UI, retrieval, LLM, and configuration layers.
