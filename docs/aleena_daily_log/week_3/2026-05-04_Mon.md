### Branch Switching Steps

#### 1. Create personal backup branch

```bash
git branch aleena
```

#### 2. Switch to updated branch

```bash
git switch udita
```

#### 3. Return to personal branch

```bash
git switch aleena
```

#### 4. Merge updated branch into personal branch

```bash
git merge udita
```
