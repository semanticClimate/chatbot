## Problems faced

- If port `8080` was already occupied by other processes (such as Maven or Tomcat), Cloudflare setup failed due to port conflicts  
- Alternative ports such as `8081` or `8082` had to be used instead  
- Required maintaining four separate terminals simultaneously:
  - Frontend  
  - FastAPI backend  
  - Cloudflare tunnel for Web UI  
  - Cloudflare tunnel for API  

- Another prevalent porblme that most users who wish to run the chatbot via cloudflare will face is installing it .... detailed version on how to install Cloudflare on Windows is specified in Cloudflare_installation.md under the week_3 folder

## API key verification

To avoid invalid GROQ API key errors:

Set the key:
```powershell
$env:GROQ_API_KEY="your_api_key_here"
```
Verify the key:

```bash
echo $env:GROQ_API_KEY
```

Exposing the API key directly is discouraged
Prefer storing it securely in a .env file instead
Errors faced
Frequent fetch failed errors while running Cloudflare tunnels
Port conflicts due to already running services
Occasional invalid API key errors due to incorrect environment variable setup
