---

### Virtual Environment Setup (recommended for all systems)

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it:

**Windows PowerShell**

```bash
.\.venv\Scripts\Activate.ps1
```

**Windows CMD**

```bash
.venv\Scripts\activate.bat
```

**Linux / macOS**

```bash
source .venv/bin/activate
```
