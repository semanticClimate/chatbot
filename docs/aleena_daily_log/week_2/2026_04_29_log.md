## Observation

- Identified that the application functions properly only in Python 3.11 or 3.12  
- Higher Python versions caused compatibility issues and application crashes  
- Version mismatch appears to significantly impact Streamlit and chatbot stability  

## Suggestions

- If using a newer Python version, downgrade to Python 3.11 or 3.12  
- Recommended versions help ensure smoother chatbot deployment and fewer dependency conflicts
