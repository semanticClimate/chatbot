## What I understood about client-server architecture

This session helped me build a basic understanding of how the chatbot system works.

- The **client** is the browser or front-end that the user interacts with  
- The **server** is the back-end that processes requests and returns responses  
- Communication happens through **HTTP requests and responses**  
- The browser sends user queries to the server  
- The server processes the request using FastAPI, databases, and LLM tools, then sends back an answer  
- The project architecture includes:
  - Web UI server  
  - API server (FastAPI)  
  - ChromaDB database  
  - Groq API / LLM integration  
  - Cloudflare tunnels for remote testing  

### In simple terms:
The user asks a question in the browser, the request goes to the server, the server processes it, and the browser displays the final response.
