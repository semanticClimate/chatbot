## What was implemented

### 1. Fixed image scaling

Based on the investigation performed previously, I modified the frontend styling responsible for rendering book content.

The update ensures that:

- images remain within their parent container,
- aspect ratios are preserved,
- oversized images no longer overflow outside the page,
- and content becomes more responsive across different screen sizes.

The required changes were applied to both the Streamlit-generated styles and the shared stylesheet so that image behaviour remained consistent throughout the application.

---

This documentation was intended to make the project easier to navigate for both current and future contributors.
