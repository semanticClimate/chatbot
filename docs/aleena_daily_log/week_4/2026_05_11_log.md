  1. Backend setup
  2. Frontend setup
  3. Backend Cloudflare tunnel
  4. Frontend Cloudflare tunnel

- The backend tunnel URL must be correctly pasted into the frontend’s API Base URL field
- Cloudflare installation should be verified beforehand using:
