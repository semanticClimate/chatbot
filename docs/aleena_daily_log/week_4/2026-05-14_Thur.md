# May 14, 2026

## Context

Today was primarily spent understanding why some display issues persisted in the chatbot interface. Rather than immediately modifying the code, I focused on tracing how the frontend rendered different types of content and identifying the files responsible for the observed behaviour.

---

## Investigation

I explored the frontend structure to understand how HTML generated by the backend was ultimately displayed inside the application.

Areas investigated included:

- The Streamlit application responsible for rendering the Climate Academy book.
- CSS files controlling the appearance of embedded content.
- The relationship between generated HTML and the iframe styling.
- How images were handled inside annotated book pages.

---

## Problems Observed

During testing, I noticed that some images were not behaving consistently.

Issues included:

- Images occasionally exceeding their container width.
- Inconsistent scaling when viewed on different screen sizes.
- Layout distortion caused by images maintaining their original dimensions.
- Reduced readability when large images pushed surrounding content out of place.

Although other elements such as tables and code blocks were constrained correctly, images still required additional styling.

---

## Root Cause

After tracing the rendering pipeline, I identified the locations responsible for controlling image presentation.

The issue was not related to the chatbot backend or API responses, but rather the frontend styling applied when displaying the Climate Academy book.

I located the relevant files where CSS rules could be updated to ensure responsive image rendering.

---

## Outcome

No code changes were committed today.

Instead, I documented the behaviour, verified the root cause, and prepared the necessary modifications for the following day.

This investigation helped me better understand:

- how the frontend rendering pipeline works,
- where embedded content styling is applied,
- and how small CSS changes can significantly improve usability.
