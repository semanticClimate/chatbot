## What was done

### 1. Fixed EMF image conversion

Some images used by the project were available in EMF (Enhanced Metafile) format, which was not suitable for direct use in the web application.

To simplify asset preparation, I developed a Python utility that:

- automatically searches for EMF files in the project's media directory,
- converts them into PNG format using the Pillow library,
- saves the converted images alongside the originals,
- and reports successful and failed conversions.

After verifying that the script worked correctly, the converted PNG images were added to the project for use by the application.

---

### 2. Added a Help window to the web client

To improve the onboarding experience for new users, I implemented an interactive Help window within the chatbot interface.

The feature included:

- a Help button accessible from the application header,
- a modal overlay explaining how to use the chatbot,
- automatic display for first-time visitors,
- the ability to reopen the guide at any time,
- multilingual support through the existing localization system,
- accessibility improvements including keyboard navigation and focus management,
- and persistence using browser local storage so the guide is not repeatedly shown.

I also created accompanying documentation explaining the architecture and usage of the Help window for future contributors.
