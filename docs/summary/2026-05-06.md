## Latest instructions (API + browser client) — 2026-05-06

Date source: system date (`date +%F` -> `2026-05-06`).

### One-time setup

From repo root (`chatbot/`):

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -U pip
pip install -r requirements.txt
```

Use **Python 3.11+** for the API (stdlib includes `tomllib`). If `python -c "import tomllib"` works but the server still failed earlier, you were almost certainly running **`uvicorn` from another Python** on `PATH` (e.g. 3.8).

### Groq key (API only; never commit)

Export in the **same** terminal session that starts the server so the process inherits it:

```bash
export GROQ_API_KEY='gsk_…'
printenv GROQ_API_KEY   # should print the key (do not log this in public artifacts)
```

The static `web_client/` does **not** need the Groq key.

### Terminal A — FastAPI (port 8800)

Always prefer the **same interpreter** as `python`:

```bash
cd /path/to/chatbot
source .venv/bin/activate
export GROQ_API_KEY='gsk_…'

python -m uvicorn fastapi_app.main:app --host 127.0.0.1 --port 8800
```

Avoid bare `uvicorn` if `which uvicorn` points at an old Python (e.g. `/Library/Frameworks/.../3.8/bin/uvicorn`). Use `python -m uvicorn`.

Sanity checks:

```bash
curl -s http://127.0.0.1:8800/health
curl -s http://127.0.0.1:8800/ready
```

`GET /` returns `404` / `Not Found` — normal; use `/health`, `/docs`, or `POST /ask`.

Example query:

```bash
curl -s -X POST http://127.0.0.1:8800/ask \
  -H "Content-Type: application/json" \
  -d '{"question":"What is CO2?","conversation":[]}'
```

### Terminal B — Vanilla web client (port 8080)

No API key in this terminal:

```bash
cd /path/to/chatbot/web_client
python -m http.server 8080
```

Open `http://127.0.0.1:8080`, set **API base URL** to `http://127.0.0.1:8800`.

### CORS

If the browser blocks requests to the API, set this **before** starting Terminal A:

```bash
export CLIMATE_API_CORS_ORIGINS=http://127.0.0.1:8080
```

(Or `*` for local dev only.)

### Python `tomllib` vs multiple Pythons

If you see `ModuleNotFoundError: tomllib`, the API process is older than 3.11 — align with `python -m uvicorn`. The repo also declares `tomli` for `python_version < "3.11"` in `requirements.txt` as a fallback.
