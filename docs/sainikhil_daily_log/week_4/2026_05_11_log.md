### Cloudflared Installation Process

While setting up the tunnels today, I encountered an issue where the scripts failed because `cloudflared` wasn't installed on my system. I took some time to understand how Cloudflare routes local ports to public URLs, and realized I needed their official tunnel daemon running locally.

Here is the step-by-step process of how I installed it on my Windows machine:

1. I went to the official [Cloudflare GitHub Releases page](https://github.com/cloudflare/cloudflared/releases) and downloaded the `cloudflared-windows-amd64.exe` file.
2. I created a dedicated folder at `C:\Cloudflared\` and moved the downloaded executable into it.
3. To make it easier to run from the command line, I renamed the file to just `cloudflared.exe`.
4. I needed PowerShell to recognize the `cloudflared` command globally, so I added the folder to my system's PATH:
   - Opened Windows search and typed "Environment Variables".
   - Edited the "Path" variable in my User variables.
   - Added `C:\Cloudflared` as a new entry and saved.
5. I opened a fresh PowerShell terminal and verified it was working by running:
   ```bash
   cloudflared --version
   ```

Once the installation was confirmed, I reran the `start-quick-tunnel.ps1` script and it successfully generated the `.trycloudflare.com` URLs!
