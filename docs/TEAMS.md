### Design

The servers are temporary (lasting a single laptop session). Approaches:

#### single developer
*Must be able to install chatbot (Python, git, etc.)*

Downloads Github chatbot and opens 2 terminals:
* 8080 FastAPI server. Terminal 1
* 8081 Web server Terminal 2

Developer starts servers and uses the book on https://127.0.0.1:8081

Then switches to exploring content. Session ends when developed logs out

#### developer + users

*Developer is IT-competent; users are not and have web browsers (e.g. ClimateAcademy)

* Developer has temporary Cloudflare account and sets up temporary server (cloudflare assigns DNS, e.g. https://xyz123.cloudflare.com)

* users browse https://xyz123.cloudflare.com , issue questions and record answers
